### About

I build web products that replace manual, error-prone workflows with reliable software, covering everything from the React interface to the secured API and the database underneath.

My work is in production today: an **admission examination platform** that ran the latest exam cycle for nearly **600 candidates** and is being rolled out across **6 university faculties**, and a **live multi-vendor marketplace** serving a campus community. I care about the parts that make software trustworthy: authentication, access control, data integrity and deployment.

📍 Dhaka, Bangladesh  ·  Open to full-stack and backend engineering roles

---

### What I Work On

- **Secure APIs.** JWT authentication, role-based access control and transactional state changes (such as order lifecycles) built with Node.js, Express and Prisma.
- **Role-based products.** Separate portals for admins, vendors, riders and end users, each with its own permissions and workflows.
- **Real-time and offline experience.** Push notifications through Firebase Cloud Messaging and offline-capable PWAs with Workbox.
- **Production delivery.** Custom domains, SSL, Nginx on a VPS, and Vercel deployments.
